# Corpus de evaluación

Los PDF de este directorio son textos legales publicados en el **BOE**:

- `estatuto-trabajadores.pdf` — Estatuto de los Trabajadores
- `ley-teletrabajo.pdf` — Ley 10/2021, de trabajo a distancia

Se incluyen para que la evaluación del sistema sea **reproducible**: las 18
preguntas del set de pruebas se responden contra estos dos documentos.

**Su titularidad no es de este proyecto.** La licencia MIT del repositorio cubre
el código, no estos PDF.

`corpus.json` es el corpus ya troceado e indexado que genera el pipeline a
partir de los PDF.
